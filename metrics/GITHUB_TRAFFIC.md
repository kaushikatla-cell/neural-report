# GitHub traffic (zero-config baseline)

Even before GA4, you can report **repository engagement**:

1. Open `https://github.com/kaushikatla-cell/neural-report`
2. **Insights → Traffic** — clones and visitors (14-day window).
3. Screenshot monthly for `metrics/screenshots/` (optional).

**Limits:** Traffic is repo-level, not per-`/briefs/` URL. Pair it with GA4 once configured (`SETUP_ANALYTICS.md`).
